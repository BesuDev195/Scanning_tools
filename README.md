# Scanning_tools with python

## installation and usage

```
git clone https://github.com/BesuDev195/Scanning_tools.git
cd Scanning_tools
```

### Give permission to execute it
```
chmod +x scanner1.py scanner2.py host_scan.py scanner.sh
```
### usage

```
python scanner1.py Ip_addr
python scanner2.py Ip_addr
python host_scan.py <Ip_addr> <ip class>
./scanner.sh  ip_addr
```

*Caution: If the scanner2 says nmap module not found use `pip install nmap-module`*
